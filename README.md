# ⚡ Projeto de Banco de Capacitores para Correção do Fator de Potência  

Este repositório apresenta o desenvolvimento de um projeto de banco de capacitores montado em painel elétrico para correção do fator de potência de uma indústria alimentícia.  
O trabalho foi elaborado como Trabalho de Conclusão de Curso (TCC) do curso de Engenharia Elétrica no Centro Universitário Hermínio Ometto (FHO).  
O projeto tem como base dados reais de uma instalação industrial no interior de Santa Catarina e foi desenvolvido em conformidade com as normas ABNT NBR 5410, NBR IEC 61439-1/2, NBR 5419, NR 10, NR 12, entre outras.

---

## 📌 Objetivos Gerais do Projeto  

- Projetar um banco de capacitores automático em painel elétrico para corrigir o fator de potência da instalação;  
- Elevar o fator de potência de 0,87 para 0,95, evitando penalidades tarifárias e melhorando a eficiência energética;  
- Reduzir o carregamento do transformador e proporcionar maior confiabilidade e segurança operacional;  
- Garantir que o projeto esteja em conformidade com as normas técnicas e boas práticas de engenharia.

---

## 🔍 Conteúdo Técnico  

O projeto aborda todas as etapas de dimensionamento, simulação e especificação dos componentes do sistema de compensação reativa, incluindo:

### ⚙️ Cálculo de Compensação Reativa  
- Levantamento da potência reativa da instalação;  
- Cálculo da potência a ser compensada para corrigir o fator de potência;  
- Definição da quantidade e configuração dos estágios.

### 🔄 Simulações e Análises  
- Simulações realizadas via software para validação dos resultados obtidos;  
- Verificação da redução de corrente e melhoria na eficiência do sistema após a compensação reativa;  
- Análise das correntes de curto-circuito trifásico e fase-terra em todos os barramentos da instalação.

### 🔌 Dimensionamento e Seleção de Componentes  
- Seleção dos capacitores trifásicos conforme a tensão nominal da instalação;  
- Utilização de reatores de dessintonia para mitigação de harmônicas e proteção dos capacitores;  
- Definição de contatores específicos para manobra de capacitores, conforme a categoria adequada de utilização;  
- Dimensionamento dos disjuntores de proteção de cada estágio e do disjuntor geral do painel;  
- Especificação do controlador de fator de potência com operação automática e comunicação industrial integrada.

### 🧮 Dimensionamento dos Condutores  
- Definição da seção dos condutores de fase conforme critérios de ampacidade, queda de tensão e curto-circuito;  
- Dimensionamento do condutor de proteção em conformidade com a NBR 5410.

### 🧱 Projeto do Painel Elétrico  
- Projeto desenvolvido em conformidade com as normas NR 10, NR 12, NBR 5410 e NBR IEC 61439-1/2;  
- Sistema de climatização dimensionado com o software RiTherm (Rittal);  
- Sistema de monitoramento térmico da Varixx, com sinalizações locais para supervisão do funcionamento;  
- Diagrama trifilar e layout 3D elaborados no EPLAN Electric P8 + Pro Panel.
